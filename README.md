## 🚀 Quick Start

### Prerequisites
- Any modern web browser
- Basic understanding of HTML/CSS/JS (for customization)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/McAnnison/MyPortfoli.git
   ```

2. **Navigate to project directory**
   ```bash
   cd MyPortfoli
   ```

3. **Open in browser**
   ```bash
   # Option 1: Direct file opening
   open index.html
   
   # Option 2: Using a local server (recommended)
   python -m http.server 8000
   # Then visit: http://localhost:8000
   ```

### 🔧 Customization

**Personalize the content:**
1. Update personal information in `index.html`
2. Replace profile images with your own
3. Modify the color scheme in `style.css`
4. Add your projects and experience
5. Update social media links
